PcanWork v0.3.29

本版本统一了发送和诊断场景中的十六进制数据编辑方式，让 CAN/CAN FD 载荷与 UDS/XCP 长数据更容易输入、检查和修改。

GitHub 下载安装包Gitee 下载安装包

更新内容

  • 发送列表载荷、触发器发送动作、UDS 和 XCP 数据字段采用统一的十六进制字节编辑器。
  • 支持连续十六进制以及空格、逗号分隔格式粘贴，输入会规范化为两位大写字节。
  • 逐字节检查有效性并准确提示错误偏移，减少手工输入报文时的隐蔽错误。
  • 支持 CAN FD 载荷和 UDS 长数据，字节网格可按实际长度扩展。
