QUICK START · 快速上手

6 步跑通完整链路

克隆后 cargo run --release，然后：

1

连接设备

自动尝试打开 PCAN_USBBUS1 @500K；没插卡自动回退虚拟总线。

2

启动接收

点「启动」，中央表格开始滚动报文。

3

加载 DBC

选择工程根目录的 sample.dbc，报文立即出现名称（EngineData / BMS_Status…）。

4

信号解析

点选任意报文，底部面板显示 Raw / Physical / 单位 / 起始位 / 字节序。

5

添加曲线

信号行点「添加」，切到曲线 Tab 看实时折线。

6

发送报文

发送 Tab → 新增 → 发一次 或 周期发送。
