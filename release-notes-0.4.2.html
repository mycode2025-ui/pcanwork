RELEASE NOTES · 2026-09-03

PcanWork v0.4.2

本版本完善周期发送任务的次数编辑与成功计数语义，同时让 CAN 通道配置在新增、编辑和全部删除后的状态都更加明确、安全。

GitHub 下载安装包Gitee 下载安装包

更新内容

  • 发送列表中的重复次数改为可编辑字段：正整数执行有限发送，空值、零或负数执行持续发送。
  • 新增周期发送进度事件，已发送数量只在报文成功写入适配器后递增；有限任务按成功次数结束。
  • 通道全部删除后使用真正的无选择状态，不再用默认通道掩盖空配置。
  • 无通道时显示绑定硬件或手动添加的操作引导，并禁止执行无效连接。
  • 通道卡片增加“编辑参数”入口，选择后自动聚焦备注输入框。
