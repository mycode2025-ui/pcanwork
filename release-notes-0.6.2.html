PCAN-Explorer10 v0.6.2

本版本修复普通发送与列表周期发送的连续性、停止操作和高频周期精度。

GitHub 下载安装包Gitee 下载安装包

更新内容

  • 修复立即发送时 ID 递增和数据递增每次从原值重新开始的问题，连续点击会从上次结果继续。
  • 修复列表周期发送任务的“停止”按钮失效；停止命令同时清理静态与动态周期任务。
  • 移除列表行内重复的删除按钮，保留底部基于勾选项的批量删除。
  • 周期发送使用 Windows 高分辨率等待定时器和绝对时限调度，改善 1 ms 与 10 ms 周期偏差。
